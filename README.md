# Antifungal Compass

一个面向儿童血液系统疾病场景的抗真菌预防辅助网页。应用根据项目提供者确认的规则，完成预防风险评估、候选药物提示和部分剂量计算，并完整展示 TDM 参考文字。

> 本项目仅用于规则数字化展示和科研/教学演示，不构成诊断、处方或个体化医疗建议。所有结果均需由具备资质的临床专业人员复核。

## 功能

- 四步式风险评估和实时规则追踪
- 按已确认项目规则生成候选药物
- 自动计算米卡芬净、泊沙康唑和卡泊芬净的明确剂量规则
- 对 18 岁以下艾沙康唑提示超说明书用药
- TDM 内容仅完整展示，不自动判定达标与否
- 所有患者输入仅在当前浏览器内处理，不上传或持久化
- 支持结果复制、打印和移动端访问

## 已实现的关键规则

- 米卡芬净：`1 mg/kg`、每日 1 次、最大 `50 mg/次`；或 `4 mg/kg`、每周 2 次。资料未给出后一方案的最大剂量。
- 泊沙康唑肠溶片：13 岁及以上首日 `300 mg`、每日 2 次，之后 `300 mg`、每日 1 次；13 岁以下不生成剂量。
- 泊沙康唑混悬液：13 岁及以上 `200 mg`、每日 3 次；1 个月至 12 岁 `6 mg/kg/次`、每日 3 次。资料未提供最大剂量或取整规则。
- QTc 延长：保留原候选药物，并增加“可考虑”艾沙康唑；18 岁以下标注超说明书用药。
- 当前疑似/确诊 IFD、影像或 G/GM 阳性、既往 IFD 史仍按资料提供者确认的原始流程进入二级预防输出；界面同时提示活动性或疑似感染需由临床团队另行判断诊疗路径。

规则实现位于 [`app/rules.ts`](app/rules.ts)，自动化测试位于 [`tests/rules.test.ts`](tests/rules.test.ts)。

## 本地运行

需要 Node.js 22.13 或更高版本，并启用 pnpm。

```bash
pnpm install
pnpm dev
```

访问终端显示的本地地址即可。正式校验命令：

```bash
pnpm test
pnpm lint
```

## 项目结构

```text
app/page.tsx            主界面与交互
app/rules.ts            纯函数规则和剂量计算
app/reference-data.ts   TDM 与药物参考文字
app/globals.css         响应式与打印样式
tests/                  规则和服务端渲染测试
```

## 维护规则

医学规则变更应由项目内容负责人书面确认后修改，并同步补充测试。对未提供完整适用条件、最大剂量或取整方式的条目，界面不得自行推断。
